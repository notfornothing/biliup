## 和上游不一样、但要留下的配置

这些只改面板 / 数据库里的运行配置，不改上游代码。

- 时区 `Asia/Shanghai`
- 文件名 / 投稿标题：`{streamer}｜%Y-%m-%d %H-%M-%S｜{title}`（全角竖线）
- 简介两行：`主播:{streamer}`、`地址:{url}`；稿件自制、仅自己可见
- 投稿通道 `submit_api = web`
- 多了一个 `/progress/` 进度页（官方仓库没有），说明见 `../progress/README.md`

## 上次在 VPS 上踩过的

**投稿不要走 App。** 提交方式空着时走 App，会被 `21566`（投稿过于频繁）拦住，换登录也没用。改成 `web` 之后，同一套登录可以投稿成功。
